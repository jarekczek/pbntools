BUILDING ZBAR

Windows (Visual Studio)
- Download zbarw
- Patch
- Download gnuwin32 iconv
- Build using Visual Studio 2022

Linux (Debian)
sudo apt-get update
sudo apt-get install mercurial autoconf gettext build-essential autoconf automake libtool pkg-config \
  libmagickwand-dev libgraphicsmagick1-dev tmux libgtk2.0-dev xmlto libxext-dev libjpeg62-turbo-dev -y
hg clone http://hg.code.sf.net/p/zbarw/code zbarw-code
cd zbarw-code
autoreconf --install
CFLAGS="-Wno-logical-not-parentheses" \
  ./configure --without-python --without-qt --without-imagemagick --without-gtk --disable-shared
make
sudo make install
make html-local
make install DESTDIR=~/zbar_installation
cd ~/zbar_installation
tar -czvf ~/zbar_build.tar.gz .

running:
sudo apt-get install libjpeg62-turbo-dev
